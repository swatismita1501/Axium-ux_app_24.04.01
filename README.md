# Arc UX handler
Android Studio project for Arc UX products.

## Building
Before building this project, ensure you have the following installed:

- **Android Studio** (Latest stable version)
- **Gradle** (Included with Android Studio)
- **JDK 17** (Required for Gradle compatibility)

### Developer build on local PC
To run builds locally, you have to:

1. Update submodules:
```shell
./update 
```

2. Run a build:
```shell
./gradlew build 
```
